# House-Price-Prediction - ML
House Price Prediction using Linear and Lasso Regression - python ML project.
## model used
- Linear Regression
- Lasso Regression (L1 Regularization)
### tech stack
- pyhton ,numpy ,pandas
- Matplotlib , seaborn
- joblib , Scikit-learn
### Results
- Evaluated using MAE , RMSE ,R2 Score
- Model saved for future predictions using joblib
## How to run 
- import library
model = joblib.load("house_prediction.ipynb")
print(model.predict([[1200,3,2,2]])
